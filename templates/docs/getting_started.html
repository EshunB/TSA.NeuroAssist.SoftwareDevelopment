Getting started

NeuroAssist is a local-first demo that runs on your machine using Python (Flask), SQLite, and the Web Speech API built into your browser.

  1. Install Python 3.10+.
  2. Create a virtual environment and install dependencies: python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
  3. Ensure the SQLite schema exists. If prisma/dev.db is missing, the app creates tables from prisma/migrations/20260226125929_init/migration.sql on first request.
  4. Start the server: python app.py and open http://localhost:5000.
  5. Navigate to /app/captions to begin live captioning.
